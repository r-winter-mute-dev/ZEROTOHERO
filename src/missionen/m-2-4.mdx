Später macht deine Klingel bei jedem Druck dasselbe: aufwachen, Foto, senden, schlafen. Damit du das nicht jedes Mal neu hinschreiben musst, fasst du es in einer **Funktion** zusammen. **Deine Mission: Programmiere ein Klingelmuster mit einer eigenen Funktion und einer Schleife.**

## Theorie

<Karte nr={1} titel="setup() und loop()">
Jedes Arduino-Programm hat zwei feste Teile: `setup()` läuft **einmal** nach dem Einschalten. Dort stellst du Pins ein und startest die serielle Ausgabe. `loop()` läuft danach **immer wieder**, ohne Ende. Darin steht, was dein Gerät dauerhaft tut.
</Karte>

<Merke>setup() läuft einmal, loop() läuft immer wieder.</Merke>

<Karte nr={2} titel="Schleifen">
`for (int i = 0; i < 3; i++) { … }` wiederholt den Code in den Klammern: Starte bei `i = 0`, wiederhole, solange `i < 3` gilt, und erhöhe `i` nach jedem Durchlauf um eins. Das ergibt genau drei Durchläufe (0, 1, 2).
</Karte>

<Merke>for (int i = 0; i < n; i++) läuft genau n-mal.</Merke>

<Karte nr={3} titel="Eigene Funktionen">
`void blinke(int anzahl, int dauer) { … }` erschafft eine neue Funktion namens `blinke`. In den runden Klammern stehen die **Parameter**: Werte, die du beim Aufruf mitgibst. `blinke(3, 150);` lässt die LED dreimal je 150 ms blinken. `void` heißt: Die Funktion gibt kein Ergebnis zurück.
</Karte>

## Auf das Board laden

```cpp
const int LED_PIN = 2;
int runde = 0;

void blinke(int anzahl, int dauer) {
  for (int i = 0; i < anzahl; i++) {
    digitalWrite(LED_PIN, HIGH);
    delay(dauer);
    digitalWrite(LED_PIN, LOW);
    delay(dauer);
  }
}

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  blinke(3, 150);
  delay(400);
  blinke(1, 600);
  delay(1500);

  runde++;
  Serial.print("Klingelmuster Runde ");
  Serial.println(runde);
  if (runde == 3) {
    Serial.printf("KW-CHECK:m-2-4:%012llX\n", (unsigned long long)ESP.getEfuseMac());
  }
}
```
