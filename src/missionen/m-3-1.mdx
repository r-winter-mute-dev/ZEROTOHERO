Deine Klingel erkennt jetzt einen Knopfdruck. Aber sie hängt noch am USB-Kabel und kann niemandem Bescheid sagen. In diesem Akt bekommt sie eine Stimme: Sie schickt dir eine Nachricht. Dafür muss sie zuerst ins Internet. **Deine Mission: Verbinde den ESP32 mit deinem WLAN.**

**Du brauchst:** dein ESP32 aus Akt 2, den Namen deines WLANs und das Passwort. Neue Bauteile brauchst du in diesem Akt nicht.

## Theorie

<Karte nr={1} titel="Funk auf 2,4 GHz">
WLAN ist Funk. Router senden meist auf zwei Frequenzbändern: **2,4 GHz** (größere Reichweite) und **5 GHz** (schneller, kürzere Reichweite). Der ESP32 in diesem Kurs kann **nur 2,4 GHz** [Espressif-Datenblatt: 802.11 b/g/n, 2,4 GHz]. Sendet dein Router beide Bänder unter einem Namen, ist das meist kein Problem. Ein reines 5-GHz-Netz findet der ESP32 dagegen nie.
</Karte>

<Merke>Der ESP32 funkt nur auf 2,4 GHz. Ein reines 5-GHz-Netz sieht er nicht.</Merke>

<Karte nr={3} titel="Signalstärke in dBm">
Wie gut der ESP32 den Router hört, zeigt der **RSSI**-Wert in **dBm**. Die Zahl ist immer negativ. Je näher an 0, desto besser: −50 dBm ist stark, −80 dBm ist schwach. ## Ins WLAN

Trag in den ersten Zeilen deinen WLAN-Namen und dein Passwort ein. Groß- und Kleinschreibung zählt.

```cpp
// 0 to Hero – Mission 3.1: Ins WLAN
#include <WiFi.h>

const char* WLAN_NAME = "DEIN_WLAN";         // <- Name deines WLANs (SSID)
const char* WLAN_PASSWORT = "DEIN_PASSWORT"; // <- Passwort

// Übersetzt den WLAN-Status in Klartext, damit du Fehler erkennst.
const char* statusText(wl_status_t s) {
  switch (s) {
    case WL_IDLE_STATUS:     return "wartet";
    case WL_NO_SSID_AVAIL:   return "WLAN nicht gefunden (Name falsch oder nur 5 GHz?)";
    case WL_CONNECTED:       return "verbunden";
    case WL_CONNECT_FAILED:  return "Verbindung abgelehnt (Passwort falsch?)";
    case WL_CONNECTION_LOST: return "Verbindung verloren";
    case WL_DISCONNECTED:    return "getrennt";
    default:                 return "unbekannt";
  }
}

void setup() {
  Serial.begin(115200);
  delay(500);
  Serial.println();
  Serial.print("Verbinde mit ");
  Serial.println(WLAN_NAME);

  WiFi.mode(WIFI_STA);              // als "Station", also wie ein Handy, das sich einwählt
  WiFi.begin(WLAN_NAME, WLAN_PASSWORT);

  unsigned long start = millis();
  wl_status_t letzter = WL_IDLE_STATUS;
  while (WiFi.status() != WL_CONNECTED && millis() - start < 20000) {
    wl_status_t s = WiFi.status();
    if (s != letzter) {
      Serial.print("Status: ");
      Serial.println(statusText(s));
      letzter = s;
    }
    delay(250);
  }

  if (WiFi.status() != WL_CONNECTED) {
    Serial.print("Keine Verbindung nach 20 Sekunden. Letzter Status: ");
    Serial.println(statusText(WiFi.status()));
    return;
  }

  Serial.println("Verbunden!");
  Serial.print("IP-Adresse (vom Router per DHCP): ");
  Serial.println(WiFi.localIP());
  Serial.print("Signalstärke (RSSI): ");
  Serial.print(WiFi.RSSI());
  Serial.println(" dBm");
}

void loop() {
  if (WiFi.status() == WL_CONNECTED) {
    Serial.printf("KW-CHECK:m-3-1:%012llX:%s\n", (unsigned long long)ESP.getEfuseMac(), WiFi.localIP().toString().c_str());
  }
  delay(5000);
}
```

## Typische Fehler

| Meldung | Wahrscheinliche Ursache | Lösung |
| --- | --- | --- |
| WLAN nicht gefunden | Name falsch geschrieben oder reines 5-GHz-Netz | Namen genau abschreiben, 2,4-GHz-Netz wählen |
| Verbindung abgelehnt | Passwort falsch | Passwort prüfen, auch Groß- und Kleinschreibung |
| Hängt bei „getrennt“ | Zu weit weg oder Router lässt keine neuen Geräte zu | Näher an den Router, Router-Einstellungen prüfen |
| Startet beim Verbinden neu | Stromversorgung bricht ein (Brownout, siehe Boss 2) | Anderes USB-Kabel oder anderen Anschluss probieren |
