## Rampen

<Karte titel="Was eine Rampe ist" nr={1}>
Statt den PWM-Wert sofort von 0 auf 200 zu setzen, erhöht das Programm ihn in vielen kleinen Schritten, zum Beispiel 50 Schritte in 0,6 Sekunden. Der Motor bekommt Zeit, Drehzahl aufzubauen. Mit der Drehzahl wächst seine Gegenspannung, und der Strom bleibt kleiner (Mission 1.2).
</Karte>

<Karte titel="Was sie bringt" nr={2}>
Weniger Spitzenstrom heißt weniger Einbruch am Akku. Die Räder haften besser, weil die Kraft langsam kommt. Getriebe und Fahrgestell werden geschont, und der Roboter kippelt nicht. Beim Bremsen gilt dasselbe in umgekehrter Richtung.
</Karte>

<Karte titel="Der Preis" nr={3}>
Eine Rampe kostet Zeit: Der Roboter reagiert etwas später. Für einen Notaus (Akt 6) ist das falsch. Dort soll er sofort stehen, also bremsen statt Rampe.
</Karte>

<Merke>Rampen senken den Spitzenstrom und schonen die Mechanik. Für den Notaus gilt: sofort bremsen.</Merke>

## In Prozent statt in PWM

Aus Mission 1.4 weißt du: Unter deinem Anlaufwert brummt der Motor nur. Wer „fahr mit 10 %“ sagt, meint aber „langsam fahren“, nicht „brummen“. Das Programm rechnet deshalb Prozent in PWM um: 0 % bleibt 0, 1 % ist der Anlaufwert, 100 % ist 255.

```cpp
const int ANLAUF = 85;   // dein Wert aus Mission 1.4

int prozentZuPwm(int prozent) {
  prozent = constrain(prozent, -100, 100);
  if (prozent == 0) return 0;
  int betrag = map(abs(prozent), 1, 100, ANLAUF, 255);
  return prozent > 0 ? betrag : -betrag;
}
```

`map(wert, vonMin, vonMax, nachMin, nachMax)` rechnet einen Wert linear von einem Bereich in einen anderen um, mit ganzen Zahlen.

## Messen: Sprung gegen Rampe

Das Programm `firmware/roboter-akt-2-fahren/r-2-3-sanft-anfahren/` fährt einmal schlagartig und einmal mit 0,6 s Rampe auf 80 % und misst beide Male den Einbruch an VM, wie in Mission 2.2. Trag vorher deinen Anlaufwert oben bei `ANLAUF` ein.

Ablauf wie beim Belastungstest: hochladen, Akku-Betrieb mit aufgebocktem Roboter, dann Akku aus, 3V3-Kabel ab und über USB auslesen. Die Nachweis-Zeile hat die Form `KW-CHECK:r-2-3:<Chip>:<Einbruch schlagartig>:<Einbruch Rampe>`.
