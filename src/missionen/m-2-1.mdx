Klingel v0 summt, aber sie ist dumm: Sie kann nur summen, solange jemand drückt. Damit die Klingel später ein Foto macht und eine Nachricht schickt, braucht sie ein Gehirn. **Deine Mission: Richte deine Werkstatt ein und erwecke das ESP32 zum Leben.**

**Du brauchst:** ein ESP32-DevKit (oft als „ESP32 DevKit V1“, „NodeMcu ESP32“ oder „ESP32-DevKitC“ verkauft, mit 30 oder 38 Pins) und ein **USB-Datenkabel**. Achtung: Viele Kabel aus Handy-Ladegeräten können nur laden, keine Daten übertragen. Damit findet der Computer dein Board nicht.

## Das erste Programm

Lege eine neue Datei an (**Datei → Neu**), ersetze alles durch diesen Code und klicke auf den Pfeil **Hochladen**.

```cpp
const int LED_PIN = 2;  // eingebaute LED vieler ESP32-DevKits

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(500);
  digitalWrite(LED_PIN, LOW);
  delay(500);
  Serial.printf("KW-CHECK:m-2-1:%012llX\n", (unsigned long long)ESP.getEfuseMac());
}
```

Unten erscheint nach einer Weile „Hard resetting via RTS pin…“. Dann ist das Programm drauf. Hat dein Board eine LED an GPIO 2, blinkt sie jetzt. Hat es keine, ist das kein Problem: Der Nachweis unten zeigt trotzdem, dass dein Programm läuft. Was jede Zeile tut, lernst du in den nächsten Missionen.

<Hinweis titel="Upload bricht ab?">
Bei manchen Boards musst du die Taste **BOOT** gedrückt halten, bis „Connecting…“ erscheint. Mehr typische Fehler kommen im Bosskampf am Ende dieses Akts.
</Hinweis>


## Gerätenachweis

Schließe den **seriellen Monitor** der Arduino IDE, falls er offen ist, sonst blockiert er den Anschluss. Klicke dann unten auf „Mit dem ESP32 verbinden“ und wähle den Port deines Boards. Das funktioniert in Chrome und Edge. In anderen Browsern öffnest du den seriellen Monitor der Arduino IDE (115200 Baud) und kopierst die Zeile, die mit `KW-CHECK` beginnt.
