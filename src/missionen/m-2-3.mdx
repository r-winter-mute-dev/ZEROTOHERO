Deine Klingel muss sich später Dinge merken („Wie oft wurde heute geklingelt?“) und Entscheidungen treffen („Ist der Akku fast leer? Dann warnen.“). Dafür gibt es Variablen und Bedingungen. **Deine Mission: Programmiere eine LED, die erst langsam blinkt und ab dem fünften Mal schnell.**

## Theorie

<Karte nr={1} titel="Variablen">
Eine **Variable** ist ein benannter Speicherplatz. `int zaehler = 0;` legt eine Variable namens `zaehler` an und setzt sie auf 0. Mit `zaehler = zaehler + 1;` erhöhst du sie um eins. Kurzform: `zaehler++;`. Jede Anweisung endet mit einem Semikolon.
</Karte>

<Karte nr={2} titel="Datentypen">
Vor dem Namen steht, was in der Variable liegt: `int` für ganze Zahlen (5, −12), `float` für Kommazahlen (3.3, im Code mit Punkt), `bool` für wahr oder falsch (`true`, `false`), `String` für Text. `const` davor heißt: Dieser Wert ändert sich nie, zum Beispiel eine Pin-Nummer.
</Karte>

<Karte nr={3} titel="Bedingungen">
`if (zaehler >= 5) { … }` führt den Code in den geschweiften Klammern nur aus, wenn die Bedingung stimmt. Vergleiche: `==` gleich, `!=` ungleich, `<` kleiner, `>` größer, `<=` und `>=`. Achtung: `=` (ein Zeichen) weist einen Wert zu, `==` (zwei Zeichen) vergleicht. Mit `else { … }` legst du fest, was sonst passiert.
</Karte>

## Auf das Board laden

Hier ist das vollständige Programm mit `setup()` und dem Gerätenachweis. Lade es hoch und schau im seriellen Monitor zu, wie der Zähler steigt.

```cpp
const int LED_PIN = 2;
int pause = 1000;
int zaehler = 0;

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(pause);
  digitalWrite(LED_PIN, LOW);
  delay(pause);

  zaehler = zaehler + 1;
  Serial.print("Blink Nummer ");
  Serial.println(zaehler);

  if (zaehler >= 5) {
    pause = 200;
  }

  if (zaehler == 10) {
    Serial.printf("KW-CHECK:m-2-3:%012llX\n", (unsigned long long)ESP.getEfuseMac());
  }
}
```

**Probier selbst:** Ändere die Zahlen. Was passiert mit `if (zaehler > 8)`? Und was, wenn du `pause = 200;` durch `pause = pause - 100;` ersetzt? Vorsicht: Wird die Pause negativ, gibt es Ärger. Wie würdest du das mit einer zweiten Bedingung verhindern?
