Bisher lag ein einzelner Motor auf dem Tisch. Jetzt bekommt der Roboter einen Körper: zwei Motoren mit Rädern, ein Stützrad, und oben drauf Steckbrett, ESP32 und Treiber. **Deine Mission: Bau das Fahrgestell zusammen und sorge dafür, dass beide Räder in dieselbe Richtung drehen.**

## Worauf es bei der Mechanik ankommt

- **Zwei Antriebsräder, ein Stützrad.** Der Roboter lenkt, indem die beiden Räder unterschiedlich schnell drehen (Mission 2.4). Das Stützrad läuft nur mit und dreht sich in jede Richtung.
- **Der Schwerpunkt.** Das schwerste Teil ist der Akku. Sitzt er tief und nah an der Achse der Antriebsräder, drücken die Räder fest auf den Boden und rutschen weniger. Sitzt er weit vorn über dem Stützrad, drehen die Antriebsräder leichter durch.
- **Nichts darf schleifen.** Kabel weg von Rädern und Zahnrädern, mit Kabelbindern oder Klebeband festmachen.
- **Abnehmbar bleiben.** Steckbrett und Akkuhalter mit Klettband oder Klebepads befestigen, damit du sie später wieder lösen kannst.

## Den zweiten Motor anschließen

Der DRV8833 hat zwei H-Brücken. Die zweite heißt B. Der linke Motor bleibt wie in Mission 1.4 an A, der rechte kommt an B. Versorgung noch wie in Akt 1: 2 × AA an VM, ESP32 am USB, gemeinsame Masse.

<Checkliste id="b" punkte={[
  'GPIO 32 an BIN1 (oft IN3), GPIO 33 an BIN2 (IN4).',
  'Rechter Motor an BOUT1 und BOUT2 (OUT3, OUT4).',
  'Roboter aufbocken: Räder in der Luft.',
]} />

Lade diesen kurzen Richtungstest hoch. Beide Räder sollen sich 2 Sekunden so drehen, dass der Roboter auf dem Boden **vorwärts** fahren würde, dann 2 Sekunden Pause.

```cpp
const int AIN1 = 25, AIN2 = 26, BIN1 = 32, BIN2 = 33, SLEEP = 27;

void motoren(int links, int rechts) {
  ledcWrite(AIN1, links > 0 ? links : 0);   ledcWrite(AIN2, links < 0 ? -links : 0);
  ledcWrite(BIN1, rechts > 0 ? rechts : 0); ledcWrite(BIN2, rechts < 0 ? -rechts : 0);
}

void setup() {
  pinMode(SLEEP, OUTPUT); digitalWrite(SLEEP, HIGH); delay(2);
  ledcAttach(AIN1, 20000, 8); ledcAttach(AIN2, 20000, 8);
  ledcAttach(BIN1, 20000, 8); ledcAttach(BIN2, 20000, 8);
}

void loop() {
  motoren(150, 150);   // beide vorwärts
  delay(2000);
  motoren(0, 0);
  delay(2000);
}
```

<Hinweis titel="Ein Rad dreht falsch herum?">
Das ist normal: Die Motoren sind spiegelbildlich eingebaut. Batterieschalter aus, dann die beiden Kabel **dieses** Motors am Treiber tauschen. Im Code änderst du nichts. So bedeutet „positiv“ ab jetzt für beide Räder „vorwärts“.
</Hinweis>
