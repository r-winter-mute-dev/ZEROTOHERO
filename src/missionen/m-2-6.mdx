Jetzt verbindest du die zwei Hälften deiner Klingel: den Knopf aus Akt 1 und das Gehirn aus Akt 2. Statt einen Summer direkt einzuschalten, meldet der Knopf dem ESP32: „Es hat geklingelt.“ **Deine Mission: Lies den Klingelknopf über einen GPIO aus.**

## Theorie

<Karte nr={1} titel="Ein Eingang misst die Spannung">
`digitalRead(4)` schaut nach, welche Spannung an GPIO 4 liegt: nahe 3,3 V ergibt `HIGH`, nahe 0 V ergibt `LOW`. Der Eingang selbst zieht dabei fast keinen Strom.
</Karte>

<Merke>digitalRead liest HIGH (um 3,3 V) oder LOW (um 0 V).</Merke>

<Karte nr={2} titel="Der schwebende Eingang">
Hängt an einem Eingang nur ein offener Taster, ist der Pin mit nichts verbunden. Er „schwebt“ und fängt Störungen ein, etwa von deiner Hand in der Nähe. `digitalRead` liefert dann zufällig mal HIGH, mal LOW. Ein Eingang braucht deshalb immer einen festen Ruhezustand.
</Karte>

<Merke>Ein offener Eingang schwebt und liefert Zufall. Er braucht einen festen Ruhezustand.</Merke>

<Karte nr={3} titel="Der Pull-up-Widerstand">
Ein **Pull-up** ist ein Widerstand vom Eingang nach 3,3 V. Er „zieht“ den Pin im Ruhezustand sanft auf HIGH. Drückst du den Taster, verbindet er den Pin direkt mit GND, und der Pin liest LOW. Das ESP32 hat solche Widerstände eingebaut: `pinMode(4, INPUT_PULLUP)` schaltet ihn ein. **Merke: gedrückt = LOW.**
</Karte>

<Merke>Mit INPUT_PULLUP gilt: gedrückt = LOW.</Merke>

## Aufbau

<Checkliste id="aufbau" punkte={[
  'USB-Kabel abziehen. Die LED aus Mission 2.5 darf stecken bleiben.',
  'Den Taster über die Mittelrinne stecken. Mit dem Durchgangsprüfer zwei Beine finden, die nur beim Drücken verbunden sind (Mission 1.7).',
  'Eins dieser Beine mit <strong>GPIO 4</strong> verbinden, das andere mit <strong>GND</strong>. Mehr nicht: Den Pull-up liefert das ESP32.',
  'Programm hochladen und den seriellen Monitor öffnen.',
]} />

```cpp
const int TASTER_PIN = 4;
int vorher = HIGH;
int zaehler = 0;
bool gemeldet = false;

void setup() {
  Serial.begin(115200);
  pinMode(TASTER_PIN, INPUT_PULLUP);  // ohne Druck: HIGH, gedrückt: LOW
  Serial.println("Drücke den Taster einige Male.");
}

void loop() {
  int jetzt = digitalRead(TASTER_PIN);
  if (vorher == HIGH && jetzt == LOW) {   // Übergang von HIGH nach LOW = Druck beginnt
    zaehler++;
    Serial.print("Gedrückt! Zähler: ");
    Serial.println(zaehler);
  }
  vorher = jetzt;

  if (zaehler >= 10 && !gemeldet) {
    Serial.printf("KW-CHECK:m-2-6:%012llX\n", (unsigned long long)ESP.getEfuseMac());
    gemeldet = true;
  }
}
```

Drück zehnmal langsam und zähl mit. Zeigt der Monitor manchmal mehr Drücke, als du gemacht hast? Dann hast du das Prellen aus Mission 1.7 gerade live gesehen. Darum kümmerst du dich in der nächsten Mission.
