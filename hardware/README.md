# Hardware

Hier entstehen die Schaltpläne (KiCad), Lochraster-Layouts und die 3D-Druck-Vorlage für das Gehäuse.

Vor dem Schreiben von Akt 5–7 wird ein kompletter Prototyp aufgebaut und vermessen: Ruhestrom, Aktivstrom, Spannungen am Akku. Erst danach werden Spannungswandler und MOSFETs endgültig festgelegt und die Toleranzbänder der Prüfungen kalibriert.
